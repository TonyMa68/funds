# Telegram基金推送服务 - 项目总结

## 概述

本项目为原有的Chrome基金扩展添加了一个独立的Telegram推送服务，可以自动推送每天基金涨跌情况到Telegram。

## 实现原理

### 1. API接口复用

完全复用原项目的基金数据API：
```
https://fundmobapi.eastmoney.com/FundMNewApi/FundMNFInfo
```

与Chrome扩展使用相同的接口，保持数据一致性。

### 2. 收益计算逻辑

完全遵循原项目的计算方式：

- **已更新净值**（当日净值已公布）：
  ```
  收益 = (当前净值 - 当前净值 / (1 + 涨跌幅 * 0.01)) * 持有份额
  ```

- **使用估值**（盘中估值）：
  ```
  收益 = (估算净值 - 单位净值) * 持有份额
  ```

### 3. 交易日判断

- 自动排除周末（周六、周日）
- 支持扩展节假日判断（可对接原项目的holiday.json）

## 核心功能

### 1. 定时推送

使用`node-cron`实现定时任务：
- 早报：交易日上午9:00
- 午报：交易日下午3:30（收盘后）

### 2. 消息格式

美观的Markdown格式消息，包含：
- 📈/📉 涨跌指示
- ✅ 净值更新标记
- 基金代码、净值、涨跌幅
- 持仓份额、当日收益
- 汇总统计（上涨/下跌数量、总持仓、总收益、收益率）

### 3. 配置管理

灵活的JSON配置文件：
- Telegram Bot Token和Chat ID
- 定时任务时间（支持自定义cron表达式）
- 基金列表（代码、名称、持仓份额）

## 技术栈

- **Node.js**: 运行环境
- **axios**: HTTP请求
- **node-telegram-bot-api**: Telegram Bot SDK
- **node-cron**: 定时任务调度

## 安全性

- ✅ 配置文件不提交到Git（.gitignore保护）
- ✅ 使用现代版本的axios (v1.6.0+)，修复已知安全漏洞
- ✅ 通过CodeQL安全扫描，无安全告警
- ✅ 不使用已废弃的API（如substr）

## 部署方式

### 1. 直接运行

```bash
npm install
npm start
```

### 2. PM2守护进程

```bash
pm2 start index.js --name funds-telegram
pm2 save
```

### 3. Docker部署

```bash
docker-compose up -d
```
